# Mobile — instrucciones iniciales

La carpeta mobile/ contendrá el proyecto Flutter. Aquí se generará el APK debug para pruebas y el código PWA cuando se habilite.

Archivos de interés:
- android/app/build/outputs/apk/debug/app-debug.apk  (se subirá a /artifacts cuando esté listo)

Para ejecutar localmente (requerido Flutter SDK):
- flutter pub get
- flutter run

Nota: en este commit sólo se incluye la estructura inicial; la app completa vendrá en commits posteriores.
