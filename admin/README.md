# Admin Panel — instrucciones iniciales

Carpeta admin/ contendrá una aplicación Next.js con el panel privado para administrar usuarios, depósitos, retiros, turnos, torneos y configuración de integraciones.

En la rama inicial se incluye la UI básica y las rutas protegidas para ADMIN. La autenticación con 2FA y la sección Integraciones estarán disponibles.
